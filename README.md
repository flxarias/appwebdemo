# appwebdemo

Aplicación web simple para gestionar una lista de la compra utilizando HTML, CSS y JavaScript.

## Uso

1. Abre `index.html` en tu navegador.
2. Usa el formulario para añadir productos indicando nombre, cantidad y categoría.
3. Marca los productos como comprados, elimínalos o vacía toda la lista.
4. La lista se guarda automáticamente en `localStorage` para mantenerla en futuras visitas.
5. Puedes exportar la lista actual como archivo JSON.
